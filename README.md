# 台鐵環島動態系統

線上版：<https://ctyangthu.github.io/tra-live/>

依臺鐵每日公告的時刻表，在台灣地圖上推算每一班自強號沿環島鐵路的位置，包括 EMU3000 新自強、普悠瑪、太魯閣、推拉式自強、柴聯自強與專開列車（如環島之星）。

## 功能

- **依日期套用班表**：使用臺鐵開放資料的每日時刻表，約涵蓋未來 60 天，每天約 130–160 班自強號。超出公告範圍的日期，暫以最近一個同星期的日期推算。
- **即時與模擬**：預設使用台灣現在時間；可切換日期、拖曳時間軸，並以 1×–900× 播放。跨午夜仍在行駛的前一天列車會繼續顯示。
- **環島地圖**：縱貫線、山線、海線、屏東線、南迴線、臺東線、北迴線、宜蘭線，支線以虛線表示。列車沿各自的實際路徑移動並靠左行駛，依車種上色（新自強為白底黑帶，普悠瑪紅、太魯閣紫、推拉式橘、其他自強藍），車頭朝行進方向，虛框表示停靠中。點選列車會在地圖上標出全程路線。
- **車種篩選**：在地圖圖例或概況卡片點選車種，即可顯示或隱藏；地圖、統計、看板、起訖查詢與時刻表會一起套用。概況的全日在線列車數依車種堆疊。
- **列車詳情**：車種與車型說明、停靠站與到開時間、通過站數、下一站、估算時速、騰雲座艙／自由座／親子／自行車車廂、60 天行駛日曆與臺鐵備註。
- **車站看板**：各站順行／逆行接下來的自強號班次。
- **起訖查詢**：任選兩站列出直達班次、行車時間與最快車次。
- **時刻表**：依方向、路線（西部幹線、東部幹線、經南迴線、西部↔東部）與車次篩選。

## 限制

- 列車位置依時刻表推算：車站之間以直線相連，加減速為估算，不含誤點等即時資訊。
- 只顯示自強號，也就是臺鐵車種代碼以 110 開頭的列車。車種依[臺鐵時刻查詢](https://www.railway.gov.tw/tra-tip-web/tip)的標示對照：

  | 車種代碼 | 臺鐵標示 | 本系統 |
  | --- | --- | --- |
  | 110G、110H、110K、110M | 自強(3000) | 新自強（EMU3000） |
  | 1107 | 普悠瑪 | 普悠瑪（TEMU2000） |
  | 1101 | 太魯閣 | 太魯閣（TEMU1000） |
  | 1108、1109、110A | 自強 | 推拉式自強（1109 附親子車廂，110A 附自行車車廂） |
  | 110F | 自強 | 柴聯自強（臺鐵備註為「柴聯自強號」） |
  | 1104、1106 | 自強(專) | 專開列車（加開班次、環島之星） |

  臺鐵網頁上 1108、1109、110A 只標示「自強」，本系統依親子車廂、自行車車廂等推拉式自強號的特徵歸類。日後若出現新的 110 開頭代碼，會先以「自強」顯示，整理程式也會提出警告。
- 本系統為非官方展示，實際行車以臺鐵公告為準。

## 專案結構

```
src/app.html                  網頁原始碼（資料以佔位字串嵌入）
data/stations.json            臺鐵車站基本資料（代碼、站名、GPS）
data/trains.json              由每日時刻表整理出的自強號班表、車站與軌道圖
data/counties-10t.json        縣市界 TopoJSON（taiwan-atlas）
data/map.json                 投影並簡化後的地圖路徑
tools/fetch_timetable.py      下載臺鐵目前公告的所有每日時刻表 JSON
tools/extract_trains.py       整理出自強號班表，並從所有列車的停站順序推出軌道相鄰關係
tools/build_map.py            產生 data/map.json
tools/build.py                組出 dist/index.html
```

## 建置

```bash
python3 tools/build.py
```

產出的 `dist/index.html` 可直接用瀏覽器開啟。推送到 `main` 後，GitHub Actions 會自動建置並部署到 GitHub Pages。

## 更新時刻表

臺鐵每天更新開放資料，約提供未來 60 天的每日時刻表。GitHub Actions 每天 04:30（台灣時間）重新下載並部署，所以線上版會自動往後延伸；下載失敗時改用 repo 裡的 `data/trains.json`。

在本機更新時，原始檔約 120 MB，放在 `raw/`，不納入版本控制：

```bash
python3 tools/fetch_timetable.py raw
python3 tools/extract_trains.py raw data/trains.json
python3 tools/build.py
```

## 資料來源

- 時刻表：[臺鐵開放資料〈鐵路時刻表 JSON〉](https://ods.railway.gov.tw/tra-ods-web/ods/download/dataResource/railway_schedule/JSON/list)
- 車站：臺鐵開放資料〈車站基本資料集〉
- 車種對照：[臺鐵時刻查詢](https://www.railway.gov.tw/tra-tip-web/tip)
- 地圖：[taiwan-atlas](https://github.com/dkaoster/taiwan-atlas)（原始資料為內政部國土測繪中心開放資料）
